# 부모로 인스타 피드 제작

@bumoro.kr — 바쁜 부모를 위한 정보 계정. 뉴스·육아꿀팁·맘카페썰·부모경제·꿀템을
"옆집 엄마가 알려주는" 톤으로 전한다.

## 명령 두 가지

| 명령 | 장수 | 구조 |
| --- | --- | --- |
| **한장** | 1장 | 표지만. 정보 본문은 전부 캡션에 담는다 |
| **여러장** | 4~6장 | 표지 + 넘버링 내지 2~4장 + 엔딩. **넘버링 필수** |

사용자가 장수를 말하지 않으면 주제의 정보량으로 정한다.
팁이 2개 이하거나 사실 한 줄로 끝나는 주제는 "여러장" 지시가 없는 한 한장으로 간다.

## 작업 순서

1. `scripts/instagram/decks.mjs` 에 덱을 추가한다 (아래 데이터 구조).
2. 사진을 `assets/photos/` 에 둔다. **사진은 사용자가 준다 — 직접 찾지 않는다**
   (컨테이너 이그레스 정책상 이미지 호스트가 전부 막혀 있음).
3. `node scripts/instagram/generate.mjs --deck=<ID>` 실행.
4. 검증 3종이 전부 조용해야 한다 (아래 "검증 게이트").
5. `scripts/instagram/captions.md` 에 캡션을 적는다.
6. 커밋 → 푸시 → `public/instagram/<ID>.zip` 을 `SendUserFile` 로 전달하고
   캡션은 채팅에 그대로 적어 준다.

## 덱 데이터 구조

```js
{
  id: 'A1-allergy', type: 'multi',        // 'multi' | 'single' | 'done'(발행완료) | 'draft'
  label: '이유식 알러지 테스트',
  photoDefaults: { photo: 'assets/photos/babyfood.jpg', pos: 'center' },
  slides: [
    { kind: 'photo', place: '이유식 알러지 테스트', cat: '육아꿀팁',
      head: ['나만 몰랐던 거야?', '알러지 테스트 3가지'] },
    { kind: 'photoBody', lead: '1. 새 재료는 하루에 딱 하나씩만',
      items: ['두세 개를 같이 넣으면 뭐 때문인지 몰라',
              '하윤이네도 그러다 처음부터 다시 했대'] },
    { kind: 'photoBody', body: ['문장형 본문은 body 로. 2~3문장.'] },
    { kind: 'photoEnd' },
  ],
}
```

- `photoDefaults` 로 한 덱은 **같은 사진·같은 크롭**을 쓴다. 음영만 카드마다 달라진다.
- `lead` 의 선행 번호(`1.` `2)`)는 템플릿이 자동으로 별도 칼럼으로 분리한다.
  두 줄로 넘어가면 숫자 뒤 글자에 맞춰 들여쓰기된다 — **수동 줄바꿈 넣지 말 것**.
- `items` 는 체크 목록(37px), `body` 는 문장형(42px). 한 카드에 섞지 않는다.

## 문구 규칙

### 표지
- **부모들 수다체**. "어머 준수 엄마 아직도 신청 안 했어?" 같은 대화 톤.
- 오프닝 패턴은 `scripts/instagram/hooks.md` 의 10가지를 **매번 다른 걸로** 쓰고
  사용 기록을 그 파일에 남긴다. 같은 패턴 연속 금지, "어머" 반복 금지.
- 등장 이름은 돌려 쓴다: 준수 · 서연 · 지호 · 하윤 · 도윤 · 시우 (실존 인물 아님).
- 킥커는 **정보 분류 그대로**: `이유식 알러지 테스트 | 육아꿀팁`.
  `TALK` 같은 톤 라벨은 쓰지 않는다.
- 팁 나열형은 표지에 **개수를 박는다**: `알러지 테스트 3가지`.

### 내지
- 카드는 `1.` `2.` `3.`, 캡션은 `①` `②` `③`.
- 마지막 줄이 짧게 남으면 **줄바꿈으로 끊지 말고 문장 자체를 고쳐** 글자수를 맞춘다.
  단어를 더하거나 어미를 늘리는 방식. 검증기가 55% 미만 줄을 잡아 준다.
- 반말 수다체를 유지하되 문장 끝을 매번 다르게: `~해` `~잖아` `~대` `~더라` `~네`.

### 캡션 (`captions.md`)
```
[본문]  후킹 한 줄 + 이모지 1개 → 정보 3~5줄 → 질문으로 마무리
[첫 댓글]  출처·주의사항·부연
[해시태그]  8~10개, 마지막은 항상 #부모로
```
- 이모지는 **주제마다 다른 것 하나만**. 🩵 반복 금지.
- 한장 세트는 카드에 못 담은 정보를 캡션 본문이 전부 진다.

## 레이아웃 (건드리지 말 것)

| 요소 | 위치 | 크기 |
| --- | --- | --- |
| 표지 킥커+헤드라인 | 하단 17% | 헤드라인 80px / 킥커 27px |
| 내지 본문 블록 | **하단 24%** | lead 50px · items 37px · body 42px |
| 계정명 `@bumoro.kr` | 좌상단 64/56 | 30px |
| 넘버링 `2 / 6` | 우상단 | 25px, 표지에는 없음 |

내지가 하단 24%인 이유: 인스타 **리포스트/스레드 UI**(친구 태그 말풍선·프로필 스티커)가
하단 20%를 덮는다. 그 아래로 내려가면 글자가 잘린다.

## 음영

`generate.mjs` 가 사진마다 자동으로 계산한다. 손대지 않는다.

- 표지: 위·아래만 고정 곡선으로 살짝. 사진이 **선명하게** 보여야 한다.
- 내지(`photoBody`) · 엔딩(`photoEnd`): **전면 균일 톤다운**. 글자가 주인공.
- 부분 그라데이션을 여러 구간으로 나누면 경계선이 보인다 — 곡선 모양은 고정하고
  진폭 두 개만 역산하는 현재 방식을 유지할 것.

## 검증 게이트 — 셋 다 조용해야 커밋

`node scripts/instagram/generate.mjs` 를 돌리면 자동으로 검사한다.

1. **가독성 검사** — 흰 글자 명도대비. 본문 4.5:1, 큰 글자 3.0:1. `전부 통과.` 가 떠야 한다.
2. **줄 채움 점검** — 가로폭 55% 미만인 줄. 뜨면 **문장을 고쳐** 채운다.
3. **세이프존** — 표지 외 카드의 텍스트 아래끝이 1053px(78%)을 넘는지.

하나라도 걸린 채로 커밋하거나 사용자에게 전달하지 않는다.

## CLI

```bash
node scripts/instagram/generate.mjs              # draft 제외 전부
node scripts/instagram/generate.mjs --multi      # 여러장 세트만
node scripts/instagram/generate.mjs --single     # 한장 세트만
node scripts/instagram/generate.mjs --deck=A1-allergy
```

산출물: `public/instagram/<ID>-NN.png`, `<ID>.zip`, `ALL-cards.zip`, `preview.html`

## 사실 확인

정책·금액·날짜는 검색 스니펫만으로 단정하지 않는다. 확인이 안 된 수치는
사용자에게 "확인 필요" 항목으로 따로 알려주고, 카드에는 단정적으로 쓰지 않는다.
맘카페·카톡방에서 가져온 사연은 이름·지역·특정 가능한 정보를 지우고 일반화한다.
