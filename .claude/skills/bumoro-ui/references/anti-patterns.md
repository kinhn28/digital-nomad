# "AI가 만든 티" 체크리스트

목업·화면·문서를 내보내기 전에 이 목록을 훑는다. 하나라도 걸리면 고친다.
왼쪽이 흔히 나오는 기본값이고, 오른쪽이 부모로다.

## 색

| ✗ AI 티 | ✓ 부모로 |
|---|---|
| 보라→파랑 그라디언트 히어로 | 네이비 그라디언트(힐링) 또는 흰 바탕 + 하늘색 면 하나 |
| 검정 바탕에 형광 연두·주황 포인트 하나 | 흰 종이 위 하늘색. 어두운 건 새벽 세계에서만 |
| 크림색(#F4F1EA) 바탕 + 세리프 + 테라코타 | 회색 종이(#F4F5F7) + Pretendard + 하늘 |
| 강조색을 3개 이상 나란히 | 하늘 하나. 상태색(코랄·앰버·초록)은 **의미가 있을 때만** |
| 하늘색 글자를 `--sky`로 씀 | 글자는 `--sky-d`, 면은 `--sky` |
| 파랑(`--blue`)을 브랜드색처럼 넓게 | 파랑은 숫자·링크·순번 배지에만 |

## 형태

| ✗ AI 티 | ✓ 부모로 |
|---|---|
| 모든 요소가 같은 radius(rounded-lg) | 24 / 16 / 14 / 10 / 7 — 크기로 위계 |
| 모든 카드에 테두리 + 그림자 둘 다 | 큰 블록은 테두리·그림자 없음. 회색 바탕이 경계 |
| 카드 왼쪽에 컬러 액센트 바(rail) | 없음. 색은 바탕이나 배지로 |
| 전부 가운데 정렬 | 왼쪽 정렬 기본. 가운데는 카드뉴스 표지 정도 |
| 아이콘 원형 배지 3개 나란한 피처 그리드 | 번호 배지 + 왼쪽 정렬 텍스트 |
| 큰 숫자 타일(KPI) 남발 | 숫자가 그 화면의 핵심일 때만 |
| `100vh` 히어로 | 내용 높이만큼. 첫 화면에 본문이 보여야 함 |

## 타이포

| ✗ AI 티 | ✓ 부모로 |
|---|---|
| Inter / Space Grotesk를 그냥 씀 | Pretendard. 못 쓰면 Inter + Noto Sans KR로 대체하고 명시 |
| 16/14/12px 정수 스케일 | 14.5 / 13.5 / 12.5 / 11.5 / 10.5 — 0.5px 단위 |
| 제목 weight 600~700 | 800 (Noto 대체 시 900) |
| 자간 기본값(0) | 본문 -.02em, 제목 -.03 ~ -.05em |
| 제목·본문 행간이 같음 | 제목 1.3~1.45, 본문 1.7~1.85 |
| `word-break` 미설정 → 한국어가 단어 중간에서 끊김 | `word-break: keep-all` |
| 영문 대문자 eyebrow("OVERVIEW") | 한국어 라벨 또는 번호 |

## 카피

| ✗ AI 티 | ✓ 부모로 |
|---|---|
| 섹션 제목 앞 이모지(📌 🎯 ✨ 💡) | 없음. 번호나 색 점 |
| 이모지 여러 개 나열 | 🩵 하나, 문장 끝에 |
| "~할 수 있습니다", "~하시기 바랍니다" | 콘텐츠는 반말, UI는 "~해요" |
| 느낌표로 텐션 올리기 | 느낌표 없음 |
| 세 줄짜리 설명 문장 | 한 문장 한 가지 |
| 지어낸 수치("평균 30% 향상") | 검증된 숫자만. 모르면 "동네마다 다름" |
| "혁신적인", "완벽한", "최고의" | 구체적인 것. "12분 만에 달린 답이었어" |
| 모든 카드에 "저장하세요" 반복 | 마지막 장에서 한 번 |

## 구조

| ✗ AI 티 | ✓ 부모로 |
|---|---|
| 01 / 02 / 03 번호를 순서가 아닌 것에 붙임 | 실제 순서(단계·연재 회차)일 때만 번호 |
| 뭐든 표로 정리 | 표는 비교·규칙일 때. 대화·이야기는 말풍선과 구분선 |
| lorem ipsum, "샘플 텍스트" | 진짜 문장. 시드 데이터도 실제로 있을 법한 대화 |
| 빈 상태로 시작하는 화면 | 목업은 항상 채워진 상태 — 대화가 오가는 중, 순위가 있는 중 |
| 다크모드를 나중에 | 새벽 모드는 부모로의 기능이다. 토큰으로 처음부터 |

## 마지막 질문

> **이 화면을 부모로 로고 떼고 보여줬을 때, 다른 서비스 화면이라고 해도
> 아무도 이상하게 생각하지 않는가?**

그렇다면 아직 부모로가 아니다. 부모로의 표식은 이 넷이다.

1. 회색 종이 위 흰 카드, 테두리 없음
2. 하늘색 하나 (글자는 `--sky-d`)
3. Pretendard 800에 좁은 자간, 넓은 행간
4. 반말 + 🩵 하나
