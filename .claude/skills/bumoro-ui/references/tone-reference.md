# 톤 레퍼런스 — 어디서 왔는가

이 스타일은 **부모로 인스타그램 콘텐츠 시안**(2026-09, 마스터 승인본)에서
추출했다. 그 문서가 부모로의 시각 언어를 처음으로 확정한 원본이고,
웹·앱·기획서 전부 같은 언어를 쓴다.

원본의 핵심 문장:

> 피드에 들어왔을 때 3초 안에 "이 계정은 정돈돼 있다"는 인상을 줘야 팔로우가
> 나와. 방법은 단순해 — **흰색(정보) · 하늘(혜택) · 네이비(힐링)** 세 톤만 쓰고,
> 네이비가 체스판처럼 박히게 배열하는 것.

이 3톤 원칙이 인스타 피드에서 나왔지만, **화면에도 그대로 적용된다**.
단어방 리스트에서 힐링·새벽 관련 블록이 네이비로 띄엄띄엄 박히면 같은 리듬이 된다.

## 검증된 컴포넌트 레시피

원본에서 실제로 쓰인 네 가지 카드 유형. 화면 컴포넌트로 옮길 때 그대로 쓴다.

### A. 혜택형 — 흰 바탕 + 파란 숫자
```
바탕 #fff · 킥커 12px/800 --sky-d · 제목 29px/800/-.05em
숫자 배지 26×26 r9 --blue 바탕 흰 글자
수치 30px/800 --blue + small 14px --g6
설명 12.5px/1.7 --g6, 강조는 --ink
주의 박스: --coral 글자 / --coral-bg 바탕 / r9 / 11.5px 800
```
손실 프레임 제목("신청 안 하면 못 받는 돈 3")과 함께 쓴다.

### B. 힐링·새벽형 — 네이비 + 달
```
바탕 linear-gradient(170deg,#10162B,#141A2E 60%,#1A2036)
시각 라벨 11px/800 --moon, 자간 .08em ("AM 3:00")
문장 22.5px/800/-.04em/행간 1.5 흰색
부연 12.5px #8E9AB8 행간 1.7
달: 34px 원 --moon + box-shadow 26px 6px rgba(244,208,111,.35),
    ::after로 같은 크기 원을 배경색으로 겹쳐 초승달
본문은 아래 정렬(justify-content:flex-end) — 위 여백이 말한다
```
**이 카드엔 CTA를 넣지 않는다.** 위로에 영업이 붙으면 둘 다 죽는다.

### C. 정보형 — 크림 바탕
```
바탕 --cream #FCFAF6  (혜택의 하늘과 구분하기 위해 크림)
질문 박스: 흰 바탕 r9 --coral 글자 + --sh-bub
제목 20px/800/-.04em, 본문 13px/1.75 --g6
하단 의료 표기: 10.5px --g5, border-top 1px dashed --line2
```

### D. 커뮤니티 발췌형 — 하늘 바탕 + 말풍선
```
바탕 linear-gradient(160deg,#EAF5F9,#F4F8FA)
질문 말풍선: 흰 바탕, 왼쪽 정렬, r15, --sh-bub
답변 말풍선: --ink 바탕 흰 글자, 오른쪽 정렬
작성자 10px/800 --g5 (답변 쪽은 --sky-l)
채택 배지: 8.5px --green 바탕 흰 글자 r4
더보기 11.5px/800 --sky-d
```
꾸미지 않은 실제 대화가 가장 강한 증거 콘텐츠다.

## 피드/리스트 리듬

```
정보(흰)  힐링(네이비)  혜택(하늘)
릴스(하늘) 커뮤니티(흰)  힐링(네이비)
혜택(하늘) 릴스(흰)     힐링(네이비)
```
네이비가 대각선으로 흐른다. **연속 두 칸에 네이비를 놓지 않는다.**

## 운영 원칙 (카피·콘텐츠에 그대로 적용)

1. 수치는 검증된 것만. 확정된 것 외 금액·비율을 지어내지 않는다.
2. 저장 유도는 마지막 장에서만.
3. 팔로우 CTA는 한 문장으로 통일. 힐링 카드엔 넣지 않는다.
4. 의료·안전은 경험 공유 선 유지.
5. 클로징은 🩵 하나.
6. 원소스 멀티유즈 — 카드뉴스를 컷 편집해 릴스로.

## 세계관 연결

인스타의 **밤 코너("재우고 아홉시 반", 수요일 21:30 고정)** 와 앱의 **새벽 모드**
(00~06시 자동 다크, 광고 미노출)는 같은 브랜드 약속이다.
새벽에 관한 것은 어디서든 네이비 + `--moon`으로 표현한다.
