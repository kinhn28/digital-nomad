# 부모로 인스타그램 캐러셀 생성기

HTML/CSS로 슬라이드를 그린 뒤 헤드리스 Chromium으로 캡처합니다. **1080×1350 (4:5)**, 2배 해상도.

```bash
npm i -D playwright        # 최초 1회
node scripts/instagram/generate.mjs
```

출력: `public/instagram/*.png` + `preview.html`(전체 미리보기)
한글이 □ 로 깨지면 시스템에 `Noto Sans KR` 을 설치하세요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `brand.mjs` | 브랜드 토큰(컬러·핸들·카테고리) — **공식 가이드 받으면 여기만 교체** |
| `slides.mjs` | 캐러셀 콘텐츠 — 보통 여기만 고칩니다 |
| `template.mjs` | 레이아웃/스타일 |
| `generate.mjs` | 렌더링 & PNG 출력 (내용 넘침 자동 경고) |

## 슬라이드 문법

- 헤드라인·노트에서 `{ }` 로 감싼 부분이 **강조색**으로 칠해집니다. 한 장에 한 덩어리만.
- 커버에 `bgImage: '/경로/사진.jpg'` 를 주면 사진 위에 그라데이션이 깔립니다.
  없으면 이모지 장식 + 웜 그라데이션으로 대체됩니다.

## 내부 슬라이드 모듈 4종

| type | 쓰임 |
| --- | --- |
| `checks` | 공감 체크리스트 / 오늘 할 일 |
| `list` | 라벨-값 정보 정리 (일정·조건·대안) |
| `steps` | 3단계 실행법 |
| `note` | 하단 한 줄 팁·마무리 |

## 레이아웃 규칙 (고정)

- 커버: 상단 중앙 핸들 · **좌하단**에 카테고리칩 → 2줄 헤드라인 → 보조문구
- 내부: 좌상단 배지 + (선택)우상단 마감칩 → 2줄 헤드라인 → 모듈 → 하단 중앙 핸들
- 헤드라인은 **항상 2줄**, 줄당 8~13자. 1줄=대상/상황, 2줄=결과/행동

> ⚠️ `slides.mjs` 의 현재 문구는 템플릿 시연용 샘플입니다. 발행 전 사실 확인된 내용으로 교체하세요.
