# 부모로 인스타그램 카드뉴스 생성기

콘텐츠 시안 문서의 4개 세트를 그대로 렌더링합니다. **1080×1350 (4:5)**, 2배 해상도.

```bash
npm i -D playwright                          # 최초 1회
node scripts/instagram/generate.mjs          # 전체
node scripts/instagram/generate.mjs --multi  # 여러장 세트만
node scripts/instagram/generate.mjs --single # 한장짜리만
node scripts/instagram/generate.mjs --deck=T-flu-talk   # 특정 세트만
```

여러장 세트는 렌더 후 `public/instagram/<세트ID>.zip` 으로 묶여 한 번에 받을 수 있습니다.

출력: `public/instagram/*.png` + `preview.html`

## 폰트

브랜드 지정 서체는 **Pretendard**(SIL OFL), 새벽 시리즈만 **Noto Serif KR**입니다.
설치돼 있지 않으면 시스템 기본 고딕으로 대체되니, 렌더링 머신에 두 폰트를 설치하세요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `brand.mjs` | 팔레트(시안 CSS의 `:root` 값) · 4개 테마 |
| `decks.mjs` | 카드 문구 — 보통 여기만 고칩니다 |
| `template.mjs` | 슬라이드 종류별 레이아웃 |
| `generate.mjs` | 렌더링 · 내용 넘침 경고 · 이전 산출물 정리 |
| `captions.md` | 세트별 캡션·해시태그 |

## 피드 3톤

문서의 그리드 규칙대로 세트마다 배경이 정해져 있습니다.

| 세트 | 테마 | 배경 | 강조 |
| --- | --- | --- | --- |
| A 혜택 | `benefit` | 하늘 `#EAF5F9` | `#2E7E9A` |
| B 새벽 | `dawn` | 네이비 `#141A2E` | 달 `#F4D06F` · 명조 |
| C 정보 | `info` | 크림 `#FCFAF6` | `#E28800` |
| D 이야기 | `story` | 흰색 | `#2B6FFF` |

네이비 세트를 대각선으로 배치하면 그리드에 쉼표가 생깁니다.

## 두 가지 발행 타입

| 명령 | 구성 | 카드 종류 |
| --- | --- | --- |
| **한장** | 사진 1장 + 헤드라인만 | `photo` 한 장 |
| **여러장** | 표지 → 본문 내지 n장 → 엔딩 | `photo` → `photoBody` × n → `photoEnd` |

- `photo` (표지·단장): 좌상단 워드마크, 좌하단 `분류 \| CATEGORY` + 2줄 헤드라인
- `photoBody` (내지): 워드마크 없음. 사진 위에 본문 문단, 우하단 `→`, 필요하면 `source`
- `photoEnd` (엔딩): 화면 전체를 고르게 눌러 가운데 워드마크 + 태그라인만
- `photoOnly`: 문구 없는 사진 한 장

워드마크는 브랜드 로고 그대로 **굵은 한글 「부모로」 + 하늘색(#8FCDE2) 밑줄 바**입니다.
바는 `em` 단위라 글자 크기를 바꾸면 같이 따라옵니다. 위치는 바꾸지 마세요.
계정은 `bumoro.kr` 입니다.

## 사진형 카드 (E 세트)

`kind: 'photo'` 는 사진을 전면에 깔고 좌하단에 `지역 | 분류` + 2줄 헤드라인만 얹습니다.
`kind: 'photoOnly'` 는 문구 없이 사진만 씁니다.

```js
{ kind: 'photo', photo: '/abs/path.jpg', place: '새벽', cat: 'STORY',
  head: ['재우고 나서야', '하루가 시작돼'] }
```

`photo` 를 비워두면 자리표시자가 렌더되니, 사진을 넣기 전 구도 확인용으로 쓰세요.
필요한 사진 규격과 촬영 목록은 `photo-brief.md` 에 있습니다.

## 슬라이드 종류

`cover`(표지) · `item`(혜택 낱장) · `dawn` / `dawnEnd`(새벽) · `qa`(정보 문답) ·
`chat`(커뮤니티 말풍선) · `end`(엔딩)

문구 안에서 `{ }` 로 감싼 부분이 강조색이 됩니다. 한 장에 한 덩어리만 쓰세요.

## 디자인 규칙

- 라운드 배지·그림자·점무늬 배경을 쓰지 않습니다. 구분은 **헤어라인 1px**로만.
- 이모지는 UI 아이콘으로 쓰지 않고, 🩵 만 엔딩에 서명처럼 씁니다.
- 상단 `부모로 · 분류` + `n/N`, 하단 `@bumoro.kr` 위치는 전 세트 고정입니다.
- 본문은 아래쪽에 붙이고 가운데를 비워, 넘기는 동안 리듬이 생기게 합니다.

> 수치·조건은 시안 문서의 문구를 그대로 옮긴 것입니다. 발행 전 최신 기준으로 확인하세요.

## 사진 없이 그리는 카드

매일 사진을 구하기 어려울 때 쓰는 카드 종류입니다. 전부 HTML/CSS로 그려서
소재를 밖에서 구할 필요가 없고, 문구만 바꾸면 그대로 재사용됩니다.

| kind | 쓰임 | 필요한 값 |
| --- | --- | --- |
| `talk` | 동네 학부모 단톡방 대화 | `room` `count` `msgs[{side,who,text}]` |
| `cal` | 달력에 날짜 표시 | `month` `lead` `blanks` `days` `on[]` `keys[]` |
| `vs` | 바뀐 숫자 대비 | `cap` `unit` `before/after(+Label)` `note` |

`blanks` 는 그 달 1일 앞에 비워둘 칸 수입니다. 월요일 시작 기준이며,
`cal 9 2026` 같은 명령으로 확인해서 넣으세요.

## 표지 규칙

표지 좌하단은 `소재 | 분류` 두 칸입니다.

```
독감 예방접종 | 건강정보
어머, 준수 엄마
아직도 신청 안 했어?
```

- **헤드라인은 수다체**로 후킹합니다 — 옆집 엄마가 말 거는 말투
- **분류 표기는 정보 그대로** 씁니다. `TALK` 같은 톤 라벨을 넣으면
  무슨 글인지 알 수 없어 저장이 안 나옵니다
- 분류 후보는 `brand.mjs` 의 `CATEGORIES` 참고
