# 표지 후킹 문구 규칙

수다체는 톤이지 공식이 아닙니다. **같은 오프닝을 반복하면 세 번째부터 안 먹힙니다.**
"어머"는 이미 두 번 썼으니 당분간 봉인합니다.

## 후킹이 약해지는 세 가지 이유

문구를 쓰기 전에 이걸 먼저 확인합니다. 세 개 다 통과 못 하면 다시 씁니다.

**1. 주제를 소개하고 있다 (약함) vs 장면 안에 들어와 있다 (강함)**

| 약함 | 왜 약한가 | 강함 |
| --- | --- | --- |
| 혁명템이 위험템 됐네 | 무슨 물건인지 모름. 말장난만 남음 | 어제 처음 뒤집었는데 |
| 알아두면 편해 | 아무 주제에나 붙는 말 | 차에서 세 시간을 어떻게 버텨 |
| 이 고민이네 | 고민이 뭔지 안 밝힘 | 조카 용돈 얼마 줘야 돼 |

읽는 사람이 **자기 집 얘기라고 느끼는 순간**에서 시작합니다.
어제 · 오늘 밤 · 이번 주말처럼 **시계가 달린 말**이 붙으면 더 세집니다.

**2. 추상어를 쓰고 있다**

혁명템 · 위험템 · 꿀팁 · 필수템 같은 말은 구체적인 물건 이름으로 바꿉니다.
`스와들업` `범퍼침대` `멀미약` `근로장려금` — 이름이 박혀야 멈춥니다.
숫자도 같은 역할을 합니다. `88일` `9월 15일` `14세까지`.

**3. 2행이 문법적으로 매달려 있다**

`뒤집기 시작하면 3가지` ← "3가지"가 절 뒤에 붙어 말이 끊깁니다.
2행은 **그 자체로 완결된 명사구**여야 합니다.

| 매달림 | 완결 |
| --- | --- |
| 뒤집기 시작하면 3가지 | 오늘 밤 뺄 것 3가지 |
| 알러지 테스트하면 3가지 | 알러지 테스트 3가지 |
| 연휴에 아프면 어디로 | 연휴에 문 여는 병원 찾는 법 |

`generate.mjs` 의 **표지 문구 점검**이 이 형태를 자동으로 잡아 줍니다.

## 오프닝 패턴 10가지 — 세트마다 다른 걸 고르기

| 패턴 | 예시 | 잘 맞는 소재 |
| --- | --- | --- |
| 상황 중계 | "어제 처음 뒤집었는데" | 지금 막 시작된 변화 |
| 코웃음 | "70일에 통잠은 무슨" | 남의 자랑글에 지친 주제 |
| 질문 던지기 | "이건 다들 어떻게 해?" | 정답이 갈리는 것 (용돈, 훈육) |
| 남 얘기 | "지호네는 벌써 신청했대" | 남보다 늦었다는 조바심 |
| 자기 고백 | "나만 몰랐나 봐, 진짜" | 몰라서 손해 본 정보 |
| 억울함 | "우리만 돈 낸 거였어?" | 무료·환급·지원금 |
| 반전 | "안 해도 되는 거였네" | 헛수고를 덜어주는 정보 |
| 시간 압박 | "이번 주 지나면 끝이야" | 마감·기한 |
| 경고 | "이거 모르면 헛걸음해" | 절차·조건이 까다로운 것 |
| 팁 흘리기 | "이건 알아두면 진짜 편해" | 실전 노하우 |
| 공감 한숨 | "올해도 이 고민이네" | 매년 반복되는 것 |

## 쓰는 법

- 1행은 장면, 2행은 완결된 명사구 + 개수
- 반말 수다체 유지하되 **문장 끝을 매번 다르게** — `~해` `~잖아` `~대` `~더라` `~네` `~야?`
- 이름은 돌려 쓰기: 준수 · 서연 · 지호 · 하윤 · 도윤 · 시우 (실존 인물 아님)
- 카톡방에 실제로 쓰인 말이 있으면 그걸 그대로 씁니다. 지어낸 말보다 셉니다
- 표지 분류 표기는 항상 정보 그대로 (`뒤집기 시작 시기 | 수면안전`)
- 팁을 나열하는 세트는 표지에 **개수를 박기** (`오늘 밤 뺄 것 3가지`)
  내지는 `1. 2. 3.`, 캡션은 `① ② ③` 으로 맞춤
- 표지 문구는 끝까지 **수다체**로. 정보체로 빠지지 말 것
- 마지막 줄이 짧게 남으면 **수동 줄바꿈(`\n`)으로 끊지 말고 문장 자체를 고쳐서** 글자수를 맞출 것.
  단어를 더하거나 어미를 늘려 줄을 채우는 방식. `generate.mjs` 의 `줄 채움 점검` 이
  가로폭 55% 미만인 줄을 잡아 주고, 아무것도 안 뜨면 통과
- 캡션 이모지는 **주제마다 다른 것 하나만**. 🩵 반복 금지
- 여러장 세트는 **무조건 넘버링**. `lead` 앞에 `1.` `2.` 를 붙이면 템플릿이
  숫자를 별도 칼럼으로 빼서, 두 줄이 되면 숫자 뒤 글자에 맞춰 들여쓴다 (수동 줄바꿈 금지)
- 내지 텍스트 아래끝은 1053px 이하. 리포스트 화면에서 하단 20%가 UI에 덮인다
- 내지 항목은 **종결형을 통일**. `~해` `~더라` 로 끝내고, `~하기` 명사형이나
  `~니까` `~고` 처럼 매달린 어미로 끝내지 않는다 (lead 만 명사형)
