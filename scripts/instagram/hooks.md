# 표지 후킹 문구 규칙

수다체는 톤이지 공식이 아닙니다. **같은 오프닝을 반복하면 세 번째부터 안 먹힙니다.**
"어머"는 이미 두 번 썼으니 당분간 봉인합니다.

## 오프닝 패턴 10가지 — 세트마다 다른 걸 고르기

| 패턴 | 예시 | 잘 맞는 소재 |
| --- | --- | --- |
| 질문 던지기 | "이건 다들 어떻게 해?" | 정답이 갈리는 것 (용돈, 훈육) |
| 남 얘기 | "지호네는 벌써 신청했대" | 남보다 늦었다는 조바심 |
| 자기 고백 | "나만 몰랐나 봐, 진짜" | 몰라서 손해 본 정보 |
| 억울함 | "우리만 돈 낸 거였어?" | 무료·환급·지원금 |
| 반전 | "안 해도 되는 거였네" | 헛수고를 덜어주는 정보 |
| 시간 압박 | "이번 주 지나면 끝이야" | 마감·기한 |
| 경고 | "이거 모르면 헛걸음해" | 절차·조건이 까다로운 것 |
| 팁 흘리기 | "이건 알아두면 진짜 편해" | 실전 노하우 |
| 공감 한숨 | "올해도 이 고민이네" | 매년 반복되는 것 |
| 발견 | "이런 게 있었네" | 몰랐던 제도·서비스 |

## 쓰는 법

- 1행은 말 거는 문장, 2행은 궁금하게 끊기
- 반말 수다체 유지하되 **문장 끝을 매번 다르게** — `~해` `~잖아` `~대` `~더라` `~네` `~야?`
- 이름은 돌려 쓰기: 준수 · 서연 · 지호 · 하윤 · 도윤 · 시우 (실존 인물 아님)
- 표지 분류 표기는 항상 정보 그대로 (`추석 연휴 병원 | 건강정보`)
- 팁을 나열하는 세트는 표지에 **개수를 박기** (`알러지 테스트 3가지`)
  내지는 `1. 2. 3.`, 캡션은 `① ② ③` 으로 맞춤
- 표지 문구는 끝까지 **수다체**로. 정보체로 빠지지 말 것
- 마지막 줄이 짧게 남으면 **수동 줄바꿈(`\n`)으로 끊지 말고 문장 자체를 고쳐서** 글자수를 맞출 것.
  단어를 더하거나 어미를 늘려 줄을 채우는 방식. `generate.mjs` 의 `줄 채움 점검` 이
  가로폭 55% 미만인 줄을 잡아 알려주고, 아무것도 안 뜨면 통과
- 캡션 이모지는 **주제마다 다른 것 하나만**. 🩵 반복 금지

## 음영은 사진마다 자동 역산

고정된 그라데이션을 쓰지 않습니다. 렌더 직전에

1. 음영 없는 사진을 찍어 세로 구간별 밝기(밝은 쪽 최악값)를 재고
2. **그라데이션 모양은 고정**해두고 — 위 띠 하나, 아래 램프 하나 —
   글자가 놓인 위치에서 필요한 어둡기가 나오도록 그 진폭만 역산합니다
3. **표지만** 아래쪽 그라데이션(위 띠 + 38~76% 램프)을 씁니다.
   표지 외 카드는 사진 전체를 고르게 눌러 **톤다운**합니다 — 부분 음영은
   글이 밝은 부분에 걸리고, 경계도 눈에 띕니다

구간마다 알파를 따로 계산하면 값이 오르내리면서 그 경계가 **띠(선)** 로 보입니다.
모양을 먼저 정하고 진폭만 맞추는 이유가 이것입니다.

밝은 사진은 더, 어두운 사진은 덜 눌러 결과가 항상 같은 톤으로 떨어집니다.
텍스트가 놓이는 구간(위 10% · 아래 40% · 엔딩 전체)은 행 평균이 아니라
**밝은 쪽 최악값**을 기준으로 눌러 글자가 묻히지 않게 합니다.

목표 곡선은 `generate.mjs` 의 `TARGET` 에 있습니다.
