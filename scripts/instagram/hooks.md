# 표지 후킹 문구 규칙

수다체는 톤이지 공식이 아닙니다. **같은 오프닝을 반복하면 세 번째부터 안 먹힙니다.**
"어머"는 이미 두 번 썼으니 당분간 봉인합니다.

## 후킹이 약해지는 세 가지 이유

문구를 쓰기 전에 이걸 먼저 확인합니다. 세 개 다 통과 못 하면 다시 씁니다.

**1. 주제를 소개하고 있다 (약함) vs 장면 안에 들어와 있다 (강함)**

| 약함 | 왜 약한가 | 강함 |
| --- | --- | --- |
| 혁명템이 위험템 됐네 | 무슨 물건인지 모름. 말장난만 남음 | 어제 처음 뒤집었는데 |
| 알아두면 편해 | 아무 주제에나 붙는 말 | 차에서 세 시간을 어떻게 버텨 |
| 이 고민이네 | 고민이 뭔지 안 밝힘 | 조카 용돈 얼마 줘야 돼 |

읽는 사람이 **자기 집 얘기라고 느끼는 순간**에서 시작합니다.
어제 · 오늘 밤 · 이번 주말처럼 **시계가 달린 말**이 붙으면 더 세집니다.

**2. 추상어를 쓰고 있다**

혁명템 · 위험템 · 꿀팁 · 필수템 같은 말은 구체적인 물건 이름으로 바꿉니다.
`스와들업` `범퍼침대` `멀미약` `근로장려금` — 이름이 박혀야 멈춥니다.
숫자도 같은 역할을 합니다. `88일` `9월 15일` `14세까지`.

**3. 1행이 반쪽짜리 문장이다 — 제일 자주 하는 실수**

카드는 스크롤 중에 0.5초 만에 읽힙니다. 한국어에서 주어를 빼는 건 자연스럽지만,
**앞뒤 맥락이 없는 카드에서는 빼면 무슨 말인지 모릅니다.**
1행은 **누가 · 무엇을 · 어떻게 됐는지가 다 들어간 완결된 대화 문장**이어야 합니다.

| 반쪽 (누가? 뭐가?) | 완결 |
| --- | --- |
| 양치만 하면 소리를 질러 | 우리 애만 칫솔 들면 도망가? |
| 신호 걸리면 바로 알아채 | 차가 멈추면 애가 바로 알아 |
| 25도로 올렸더니 바로 올라와 | 온도 올렸더니 태열이 올라와 |
| 30분 걸리면 바꿔야 되는 줄 | 30분씩 걸리면 바꿔야 돼? |

자가 점검: **1행만 따로 떼서 카톡방에 보냈을 때 그대로 말이 되는가?**
안 되면 주어나 목적어가 빠진 겁니다. 두 글자 더 쓰더라도 채워 넣으세요.

**4. 2행이 문법적으로 매달려 있다**

`뒤집기 시작하면 3가지` ← "3가지"가 절 뒤에 붙어 말이 끊깁니다.
2행은 **그 자체로 완결된 명사구**여야 합니다.

| 매달림 | 완결 |
| --- | --- |
| 뒤집기 시작하면 3가지 | 오늘 밤 뺄 것 3가지 |
| 알러지 테스트하면 3가지 | 알러지 테스트 3가지 |
| 연휴에 아프면 어디로 | 연휴에 문 여는 병원 찾는 법 |

`generate.mjs` 의 **표지 문구 점검**이 이 형태를 자동으로 잡아 줍니다.

## 말투 — 설명하지 말고 수다를 떨어라

내지 문장이 노잼이 되는 이유는 하나입니다. **정보를 전달하고 있어서**입니다.
부모방 대화는 정보 전달이 아니라 **경험담 + 판정**입니다.

| 노잼 (설명) | 재밌음 (수다) |
| --- | --- |
| 짧게 쓰는 물건은 중고가 경제적입니다 | 새로 사봐야 반년 쓰고 베란다로 직행이더라고 |
| 백일상은 대여를 권장합니다 | 백일상이랑 돌한복은 사면 그날 하루 쓰고 짐이야 |
| 아기띠는 착용해보고 구매하세요 | 아기띠는 꼭 매보고 사, 안 그러면 나처럼 후회해 |
| 공구가 항상 저렴하지는 않습니다 | 제일 싸다더니 검색하면 더 싼 데가 꼭 나오잖아 |

수다로 바꾸는 네 가지 장치:

1. **결과를 그림으로 보여준다** — "비효율적" 대신 "베란다로 직행", "창고행"
2. **화자가 당해봤다** — "나처럼 후회해", "우리도 그러다 다시 했잖아"
3. **되묻는다** — "~잖아", "~거든", "~더라고" 로 끝내 동의를 구한다
4. **구체적인 물건과 숫자** — "육아용품" 대신 "디럭스 유모차, 범보의자"

금지: `~합니다` `~하세요` `~권장` `~필요합니다` 같은 안내문체.
카드에서는 **끝까지 반말 수다체**. 존댓말은 캡션에서만 씁니다.

## 공감형 세트 — 정보가 아니라 마음이 목적일 때

`남편 육아분담` `독박육아` 처럼 정보보다 공감이 목적인 주제가 있습니다.
이때 지켜야 할 것:

- **누구를 탓하지 않는다.** 브랜드 계정이 배우자를 욕하면 절반이 등을 돌린다.
  탓하는 대신 **안 보이던 일에 이름을 붙인다** ("기획노동", "티 안 나는 육아")
- 항목은 지시가 아니라 **장면**으로 쓴다 — "~해야 한다" 금지, "~하고 있잖아" 로
- 마지막 카드나 캡션에 **나눌 방법 한 가지**는 넣는다. 하소연으로만 끝내지 않는다
- 표지 사진은 주제와 어긋나지 않게. 분담 얘기에 아빠가 잘 돌보는 사진이면
  탓하는 글이 아니라는 신호가 되어 오히려 맞다

## 구성은 매번 바꾼다 — 3가지 고정 금지

`~3가지` 만 계속 쓰면 계정 전체가 똑같아 보입니다.
주제의 모양에 맞는 구성을 고릅니다.

| 구성 | 언제 | 예 |
| --- | --- | --- |
| 순서형 `1·2·3` | 하는 순서가 있는 것 | 새벽수유 끊는 순서 |
| 체크형 `1·2·3` | 병렬 점검 항목 | 뒤집기 시작하면 뺄 것 |
| VS형 | 둘로 갈리는 판단 | 당근할 것과 새로 살 것 |
| 개수 없음 | 사실 하나가 핵심일 때 | 한장 세트 |

항목 수도 2~5개 사이에서 **주제가 요구하는 만큼만** 씁니다.
`generate.mjs` 가 세트별 항목 수를 출력하니 직전 세트와 겹치는지 보고 정합니다.

| 패턴 | 예시 | 잘 맞는 소재 |
| --- | --- | --- |
| 상황 중계 | "어제 처음 뒤집었는데" | 지금 막 시작된 변화 |
| 코웃음 | "70일에 통잠은 무슨" | 남의 자랑글에 지친 주제 |
| 소문 | "유모차를 7대 받아왔대" | 무용담이 있는 주제 |
| 질문 던지기 | "이건 다들 어떻게 해?" | 정답이 갈리는 것 (용돈, 훈육) |
| 남 얘기 | "지호네는 벌써 신청했대" | 남보다 늦었다는 조바심 |
| 자기 고백 | "나만 몰랐나 봐, 진짜" | 몰라서 손해 본 정보 |
| 억울함 | "우리만 돈 낸 거였어?" | 무료·환급·지원금 |

| 공감 한숨 | "올해도 이 고민이네" | 매년 반복되는 것 |

## 쓰는 법

- 1행은 장면, 2행은 완결된 명사구 + 개수
- 반말 수다체 유지하되 **문장 끝을 매번 다르게** — `~해` `~잖아` `~대` `~더라` `~네` `~야?`
- 이름은 돌려 쓰기: 준수 · 서연 · 지호 · 하윤 · 도윤 · 시우 (실존 인물 아님)
- 카톡방에 실제로 쓰인 말이 있으면 그걸 그대로 씁니다. 지어낸 말보다 셉니다
- 표지 분류 표기는 항상 정보 그대로 (`뒤집기 시작 시기 | 수면안전`)
- 팁을 나열하는 세트는 표지에 **개수를 박기** (`오늘 밤 뺄 것 3가지`)
  내지는 `1. 2. 3.`, 캡션은 `① ② ③` 으로 맞춤
- 표지 문구는 끝까지 **수다체**로. 정보체로 빠지지 말 것
- 마지막 줄이 짧게 남으면 **수동 줄바꿈(`\n`)으로 끊지 말고 문장 자체를 고쳐서** 글자수를 맞출 것.
  단어를 더하거나 어미를 늘려 줄을 채우는 방식. `generate.mjs` 의 `줄 채움 점검` 이
  가로폭 55% 미만인 줄을 잡아 주고, 아무것도 안 뜨면 통과
- 캡션 이모지는 **주제마다 다른 것 하나만**. 🩵 반복 금지
- 여러장 세트는 **무조건 넘버링**. `lead` 앞에 `1.` `2.` 를 붙이면 템플릿이
  숫자를 별도 칼럼으로 빼서, 두 줄이 되면 숫자 뒤 글자에 맞춰 들여쓴다 (수동 줄바꿈 금지)
- 내지 텍스트 아래끝은 1053px 이하. 리포스트 화면에서 하단 20%가 UI에 덮인다
- 내지 항목은 **종결형을 통일**. `~해` `~더라` 로 끝내고, `~하기` 명사형이나
  `~니까` `~고` 처럼 매달린 어미로 끝내지 않는다 (lead 만 명사형)
