# 사진 브리프

이 계정 포맷에서 지면의 90%는 사진입니다. 카드 품질은 레이아웃이 아니라 **사진 한 장**에서 갈립니다.
아래 규격만 지키면 `decks.mjs` 의 `photo:` 에 경로를 넣는 것으로 끝납니다.

## 규격

- 세로 4:5, 최소 **1080 × 1350** (권장 2160 × 2700)
- 하단 35%는 어두운 그라데이션이 덮이므로 **중요한 피사체를 아래쪽에 두지 말 것**
- 얼굴이 나오면 초상권 확인. 아이 얼굴은 원칙적으로 쓰지 않기
- 위에서 아래로 찍은 정면 구도보다, **눈높이에서 한 장면을 그대로** 담은 사진이 강함

## 상황별 촬영 목록 (부모로 소재)

| 세트 | 필요한 장면 | 비고 |
| --- | --- | --- |
| 새벽 | 수유등만 켜진 방, 창밖이 아직 어두운 거실, 새벽 시계 | 인물 없이도 성립 |
| 혜택 | 주민센터 창구·번호표, 서류 봉투, 통장 | 개인정보 가림 필수 |
| 정보 | 어린이집 현관, 약봉투, 체온계 | 제품 로고 노출 주의 |
| 이야기 | 어질러진 거실, 새벽에 켜진 휴대폰 화면 | 대화 캡처는 각색 표기 |
| 공구·꿀템 | 물건 하나만 정면에서, 배경 단순하게 | 협찬은 표기 의무 |

## 텍스트 없는 장을 반드시 넣기

캐러셀 2~3번째에 **문구 없이 사진만 있는 장**을 한 장 넣으세요.
`{ kind: 'photoOnly', photo: '...' }` 로 렌더됩니다. 넘기는 리듬이 여기서 생깁니다.

## 워드마크

좌상단 `bumoro` 세리프 이탤릭은 전 카드 고정입니다. 위치·크기를 바꾸지 마세요.
브랜드 각인은 반복에서 나옵니다.


## 이번 세트에 필요한 사진 (N-childallowance)

`decks.mjs` 의 각 슬라이드 `need` 값에 적어뒀습니다. 렌더된 자리표시자에도 그대로 표시됩니다.

| 장 | 필요한 장면 |
| --- | --- |
| 1 표지 | 초등 저학년 아이의 뒷모습 또는 등굣길 (얼굴 X) |
| 2 | 입금 알림이 뜬 휴대폰 화면 또는 통장 (개인정보 가림) |
| 3 | 교실이나 학교 복도, 아이 없는 빈 공간 |
| 4 | 지방 소도시 전경 또는 지도 화면 |
| 5 | 주민센터 창구나 번호표 |
| 6 엔딩 | 평범한 집 거실이나 창밖, 조용한 장면 |
