# 시드 대화 넣는 법

빈 커뮤니티는 아무도 안 쓴다. 첫 화면에 대화가 이미 오가고 있어야 한다.
여기에 파일을 넣으면 단어방별로 대화가 깔린다.

## 두 가지 방법

### A. 카카오톡 대화 내보내기 (가장 쉬움)

카톡에서 `채팅방 → 메뉴 → 대화 내보내기 → 텍스트만`으로 받은 `.txt`를
이 폴더에 그대로 넣는다. 파일명을 **단어와 같게** 하면 그 방으로 들어간다.

```
seed/kakao/통잠.txt
seed/kakao/기저귀.txt
seed/kakao/수족구.txt
```

파싱하면서 이렇게 처리한다:

- **닉네임은 전부 가명으로 바꾼다.** 원본 이름은 저장하지 않는다.
  같은 사람은 같은 가명으로 유지돼서 대화 흐름은 살아 있다.
- 전화번호·주소·계좌번호·링크는 **자동으로 지운다.**
- 사진·이모티콘·파일 줄(`사진`, `이모티콘`)은 건너뛴다.
- 날짜는 **최근 2주 안으로 당겨서** 배치한다. 3년 전 대화가 그대로 보이면
  죽은 커뮤니티처럼 보인다.
- 10자 미만 단답(`ㅇㅇ`, `ㅋㅋ`)은 절반만 남긴다. 전부 넣으면 지저분해진다.

> 넣기 전에 확인 — 대화 참여자에게 동의를 받았는지, 아니면 본인 대화인지.
> 남의 대화를 그대로 올리는 건 가명 처리와 별개 문제다. 애매하면 B로 간다.

### B. 직접 쓴 JSON

`seed/data.json`에 아래 형식으로 쓴다. `example.json`이 그대로 돌아가는 예시다.

```jsonc
{
  "profiles": [
    { "handle": "hayul",  "nickname": "하율맘",  "role": "두 아이 · 동작구" }
  ],
  "words": [
    { "slug": "sleep", "title": "통잠", "category": "용어",
      "intro": "수면 퇴행부터 통잠 성공기까지",
      "leader": "hayul" }
  ],
  "messages": [
    { "word": "sleep", "author": "hayul", "body": "저희는 3주쯤 지나니 돌아왔어요",
      "minutesAgo": 14 }
  ],
  "threads": [
    { "word": "sleep", "author": "hayul", "title": "수면교육 3일차인데 계속 울어요",
      "hoursAgo": 9,
      "replies": [ { "author": "hayul", "body": "…", "accepted": true } ] }
  ]
}
```

`minutesAgo` / `hoursAgo`는 **실행 시점 기준 상대 시간**이다. 절대 날짜를 쓰면
시드를 넣은 날짜가 그대로 굳어버린다.

## 넣는 명령

```bash
npm run seed          # data.json + kakao/*.txt 전부
npm run seed -- --dry # 뭐가 들어갈지만 출력하고 쓰지 않음
```

`--dry`로 먼저 확인하는 걸 권한다. 가명 치환이 제대로 됐는지, 지워야 할
개인정보가 남아 있는지 눈으로 보고 넣는다.

## 카테고리

`words[].category`는 다섯 개 중 하나다.

| 값 | 뜻 |
|---|---|
| `용어` | 통잠, 등센서, 이유식거부처럼 부모만 아는 단어 |
| `증상` | 수족구, 열성경련 — 의료 표기가 자동으로 붙는다 |
| `지역` | 동작구, 상도동 |
| `육아템` | 유모차, 아기띠, 수유등 |
| `일상` | 주말나들이, 복직, 둘째고민 |

브랜드 이름(하기스·팸퍼스 등)은 단어가 될 수 없다. 브랜드는 협찬 단어로만 열린다.
